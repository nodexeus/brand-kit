Typeface

Two families: GeistSans for UI, headings, and body copy; GeistMono for anything technical or data-shaped: status displays, code, hex values. This kit doesn't vendor the actual font files (no build step, no font licensing to manage here); pages fall back to the system sans/mono stack. Get the real fonts from vercel/geist-font if you need pixel-accurate rendering.

Usage

  • GeistSans for all UI copy: headings, body, buttons, nav.

  • Default weight 400 for body text; 600-800 for headings and emphasis, never for full paragraphs.
